01 — About

Systems that people actually depend on

I've independently led and contributed to six production systems currently in active use, spanning payroll, biometric attendance, event ticketing, fleet management and mobile sales analytics , alongside internal platforms for Durban University of Technology and client-facing mobile applications.

I'm comfortable across React 19, Flutter, Node.js, PostgreSQL, Firebase, Prisma ORM, AWS and WebSockets. I care most about the unglamorous parts: correct data models, enforced permissions, and real-time state that doesn't drift.

I hold a Bachelor of Information and Communications Technology from Durban University of Technology.

  • Security first

    Role-based access enforced server-side, not just hidden in the UI. JWT, Passport, row-level security.

  • Real-time by default

    WebSocket-driven state that stays in sync across modules , and cache keys that don't go stale.

  • Tested and reviewed

    Jest, Vitest and React Testing Library across the stack, plus reviewing team members' code as lead developer.
